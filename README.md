# ⚡ KEV TECH & FIRE — 2026tech

Application web progressive (PWA) autonome : diagnostic technique automobile,
étude incendie par véhicule, expertise juridique, catalogue photos de pannes,
recherche de campagnes par VIN et lecture OBD Bluetooth.

**Aucun serveur, aucun compte, aucun token requis.** Tout fonctionne hors ligne
grâce à une base technique embarquée et à un Service Worker.
